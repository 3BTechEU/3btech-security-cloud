# 3BTech Security Cloud

## Projekt célja

A 3BTech Security Cloud egy felhőalapú biztonságtechnikai platform, amely különböző gyártók riasztó- és biztonsági rendszereit képes egységes felületen kezelni.

## Tervezett támogatott rendszerek

- H700
- VESTA
- U-Prox
- Hikvision
- Paradox
- LoRa eszközök

## Fő komponensek

- Docker
- Portainer
- PostgreSQL
- FastAPI
- Nginx Proxy Manager
- SIA DC-09 Receiver
- Notification Service
